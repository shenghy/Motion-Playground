# 核心指标与叙事说明文字可读性改版设计

日期：2026-08-11

## 目标

本次改版只处理两个已有动效：

1. 重做“核心指标（metric-focus）”的信息层级，让主数字成为第一视觉焦点，并彻底移除柱状图元素。
2. 将“叙事（narrative）”底部说明文字提高两个字号层级，在不越过现有画面边界和字幕安全区的前提下提升可读性。

不调整其他动效，不改变参数结构，不改变 1920×1080、30fps、ProRes 4444 Alpha 的导出合同。

## 视觉方向

### 核心指标：数字海报

采用已确认的 A 方案“数字海报”。画面继续使用现有深色、冷白、工程蓝语言，内容从上到下排列为：

- 指标眉题；
- 超大主数字及前后缀；
- 蓝色水平分隔线；
- 说明文字；
- 趋势文字。

删除当前位于数字右侧的单柱轨道、填充柱和柱体生长动画。释放出的横向空间全部归还主数字，主数字通过现有排版计算按实际位数、前缀和后缀自适应缩放。数字计数、轻微缩放和模糊消散入场继续保留。

信息优先级固定为“主数字 > 说明 > 趋势”。单位与趋势继续使用工程蓝，主数字使用冷白，说明文字提高对比度，但不增加新的图表、徽章或装饰容器。

### 叙事：只放大底部说明文字

上方眉题、两行大标题、分隔线及其动画保持不变。仅调整底部 `explanation`：

- Canvas 字号从 22px 提高到 30px；
- 使用稳定行高，最长 32 个字符允许排成最多两行；
- 文字仍从现有左侧起点开始，最大宽度不超过叙事左半区；
- 第二行底部不得进入字幕安全区；
- 保留现有淡入和垂直位移动画。

换行必须基于 Canvas 实际文本测量，不能依赖强制横向压缩，否则会损失放大字号带来的可读性。

## 实现边界

实时预览和透明导出共用 Canvas 渲染器，因此视觉实现以以下模块为准：

- `src/motion/canvas/metricFocusRenderer.ts`
- `src/motion/metricFocusLayout.ts`
- `src/motion/canvas/metricFocusState.ts`
- `src/motion/canvas/narrativeRenderer.ts`

如需复用换行逻辑，应添加一个职责单一、可测试的 Canvas 文本布局辅助函数；不得建立第二套仅供预览使用的 DOM/CSS 实现。

`metric-focus` 与 `narrative` 的参数字段、默认内容和控制面板合同保持兼容，现有项目文件无需迁移。

## 状态与数据流

核心指标仍由参数生成稳定的最终排版，再由本地播放时间驱动数字计数、透明度、缩放、模糊和分隔线揭示。柱状图状态从状态模型和渲染流程中移除，不再产生无意义的绘制调用。

叙事说明文字先根据最大宽度测量并拆分为一至两行，再将同一组动画透明度和位移应用到每一行。输入为空时继续使用现有回退说明文字。

## 边界与失败处理

- 核心数字包含最长允许前缀、两位小数和最长后缀时，全部可见内容必须位于画面左侧 38% 安全区。
- 叙事说明文字最多接受注册表允许的 32 个字符；超过单行宽度时换成两行，而不是越界或横向挤压。
- 若单个不可分割字符序列超过一行，按可容纳字符逐个断行。
- 任何空字符串仍走当前回退文案，不引入新的运行时错误状态。

## 验证

自动化测试至少覆盖：

1. 核心指标渲染器不再调用柱状图矩形绘制路径。
2. 长数字、前缀和后缀的右边界不超过左侧 38% 安全区。
3. 核心指标保留数字计数和现有入场视觉属性。
4. 叙事说明文字使用 30px 字号。
5. 最长 32 字说明被限制为最多两行，所有行的右边界和底部边界均合法。
6. 相关单元测试、完整测试套件和生产构建通过。
7. 在真实 1920×1080 预览中人工检查默认内容与最长内容，确认数字直观、说明清晰且不侵入字幕区域。

## 完成标准

- “核心指标”画面中不存在柱条、柱轨或柱状动画。
- 观看者第一眼可以识别主数字及单位，说明和趋势层级清楚。
- “叙事”底部说明文字明显大于当前版本，上方标题完全不受影响。
- 实时预览与透明导出帧保持一致，且所有安全区与导出合同不变。
