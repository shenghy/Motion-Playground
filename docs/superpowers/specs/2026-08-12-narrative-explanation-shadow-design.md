# 叙事卡片底部说明文字阴影设计

## 背景

叙事卡片的两行白色大标题已有深灰色阴影，但底部白色说明文字在明亮或复杂背景上仍不够清晰。本次只增强底部说明文字的可读性，不改变其字号、换行、位置和边界规则。

## 已选方案

采用“轻量均衡”阴影：

- 颜色：`rgba(38, 40, 43, 0.8)`
- 模糊半径：`6px`
- 水平偏移：`2px`
- 垂直偏移：`3px`

它沿用大标题阴影的深灰色和 80% 透明度，但模糊与偏移更小，使 30px 说明文字保持清晰，不产生与大标题相同的厚重感。

## 渲染范围

- 阴影只应用于 `explanation` 实际绘制出的每一行白色说明文字。
- 两行白色大标题继续使用现有参数：模糊 `10px`，偏移 `4px / 5px`。
- 蓝色眉题、蓝色分隔线和其他非说明文字不新增阴影。
- 继续使用 Canvas 文本绘制原语已有的 `shadow` 选项，不增加第二套绘制路径，从而保持实时预览与 Canvas 导出一致。

## 排版与安全边界

本次不改动说明文字现有排版契约：

- 字号保持 `30px`。
- 最多两行。
- 沿用 `layoutNarrativeExplanation` 的测量和均衡换行逻辑。
- 文本坐标、行距、最大宽度和底部安全边界均保持不变。
- 阴影只改变像素外观，不参与文本测量，因此不会压缩文字或改变换行结果。

## 测试与验收

自动化测试应确认：

1. 两行大标题仍使用现有的较强阴影参数。
2. 每一行说明文字都使用新的轻量阴影参数。
3. 蓝色眉题及其他文字保持无阴影。
4. 原有 30px、最多两行、完整保留字符和安全边界测试继续通过。
5. 叙事 Canvas 测试、相关回归测试和项目构建通过。

浏览器视觉验收应确认：说明文字在灰亮背景上更清楚，同时阴影明显弱于两行大标题，且没有出现截断或越界。

## 非目标

- 不调整大标题阴影。
- 不调整说明文字颜色、字号、字重、位置、行距或动画。
- 不修改其他卡片或全局文本阴影。
