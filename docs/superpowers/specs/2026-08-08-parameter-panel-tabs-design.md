# 参数面板标签化与侧栏布局优化设计

## 背景

当前左侧组件列表使用可见的原生滚动条，鼠标进入或内容溢出时会同时出现横向、纵向滚动条，破坏界面稳定性。右侧参数面板宽度不足，并把导出、项目文件、工作区、视频背景、舞台辅助和卡片参数全部堆叠在同一长列表中，文字偏小且信息层级不清晰。

本次修改延续现有 Precision Monolith 的黑、白、灰主视觉，并继续使用深蓝色作为辅助色。

## 目标

1. 左侧组件列表不显示任何滚动条，同时保留鼠标滚轮和触控板的纵向滚动能力。
2. 右侧参数面板在桌面宽度下增加 150px，并在较窄窗口中保持可用的响应式布局。
3. 右侧面板改为深灰色层级，提升主要文字、说明文字和控件文字的字号与可读性。
4. 使用顶部三标签组织现有功能，避免单一超长信息流。
5. 保留全部现有参数、导入、导出、视频和工作区功能，不改变数据与导出协议。

## 布局方案

### 左侧组件列表

- `.rail-list` 保持 `overflow-y: auto`，允许滚轮和触控板滚动。
- 使用标准 scrollbar 隐藏规则覆盖 Chromium、Firefox 等浏览器。
- 设置 `overflow-x: hidden`，组件卡片和悬停状态不得产生横向位移或横向滚动。
- 左栏标题和底部状态栏保持固定，只有组件列表区域滚动。

### 右侧参数面板宽度

- 默认桌面布局在当前最大 320px 的基础上增加 150px，右栏目标范围为 420–470px。
- 1400px 以下断点从当前 284px 调整为约 420px。
- 1120px 以下保留紧凑回退宽度，避免主预览区失去基本可用空间。
- 右栏加宽只影响工作区网格分配，不修改画布、导出尺寸或视频比例。

## 参数面板信息架构

采用顶部三标签方案：

### 卡片属性

- 舞台辅助与人物安全区开关。
- 当前选中卡片的全部文本、数字、选择项参数。
- 固定底部操作：恢复默认、重新播放。

### 导入导出

- 视频背景导入、更换与移除。
- JSON 项目导入与导出。
- 透明 MOV 与 PNG 序列导出以及导出进度。

### 工作区

- 工作区说明和本地状态。
- 清空工作区操作及其禁用状态。
- 清空操作继续使用原有确认和错误处理流程。

## 交互设计

- 默认激活“卡片属性”标签，使用户进入页面后直接编辑当前卡片。
- 标签使用语义化 `tablist`、`tab` 和 `tabpanel`，支持点击、Tab 聚焦以及方向键切换。
- 切换标签只改变面板内容可见性，不重置卡片参数、视频、导出状态或工作区数据。
- 切换当前卡片时仍停留在“卡片属性”标签；用户主动选择其他标签后保持所选标签。
- 导出期间相关禁用状态继续生效，标签切换不取消导出任务。

## 视觉设计

- 参数面板使用更明确的深灰背景层级：外层深灰、标签栏中灰、内容分组稍浅灰。
- 激活标签使用现有深蓝辅助色，非激活标签保持中性灰。
- 面板标题提升至约 18px；标签文字约 12px；字段标签和按钮约 12–14px；说明文字约 10–12px。
- 分组使用间距、背景差和细分隔线建立层级，不引入厚重卡片边框。
- 保留现有 Noto Sans SC、Syne 和 IBM Plex Mono 字体体系。

## 组件边界

- `ParameterPanel` 管理标签状态与内容分组，不改变外部属性接口的数据含义。
- 现有 `ExportPanel`、`ProjectFileControls`、视频设置和工作区操作继续复用，只调整装配位置和样式。
- 标签定义保持在参数面板内部，避免把纯界面状态写入项目持久化数据。
- `ComponentRail` 不需要新增状态，只通过 CSS 修正滚动与溢出表现。

## 测试与验收

1. 左侧组件区不显示横向或纵向滚动条，滚轮和触控板仍可上下浏览全部组件。
2. 桌面宽度下右侧面板比当前实现增加 150px，较窄窗口仍可正常使用。
3. 默认显示“卡片属性”，其他两个标签内容初始隐藏。
4. 三个标签能够通过鼠标和键盘切换，并拥有正确的 ARIA 状态。
5. 导出、项目文件和视频操作集中在“导入导出”。
6. 清空工作区集中在“工作区”。
7. 当前卡片的参数、舞台辅助、恢复默认和重新播放集中在“卡片属性”。
8. 原有参数编辑、视频导入、JSON 导入导出、透明导出和清空工作区测试继续通过。
9. 运行完整测试、ESLint、生产构建并通过浏览器视觉检查。

## 非目标

- 不修改动效卡片本身的视觉或动画。
- 不修改透明导出格式、分辨率、帧率和 Alpha 协议。
- 不把当前标签写入持久化工作区。
- 不重新设计中间预览舞台或底部时间轴。
