# Motion Playground 第一阶段设计规格

## 目标

从空目录创建一个 React + TypeScript + Vite 项目，交付浏览器内运行的高级短视频动效组件预览台。第一阶段只负责组件选择、1920×1080 等比预览、实时参数调整和循环播放。

明确不做：完整剪辑软件、素材管理、时间轴、Remotion、ffmpeg、视频编码与导出。

## 视觉方向

采用 **Precision Monolith**：

- 主色为黑、炭灰、冷白，状态色只使用低饱和冷灰。
- 通过极细分割线、负空间、精密数字排版和轻微网格营造科技感。
- 几乎不使用投影；层级依靠明度、边界和排版建立。
- 画面不使用渐变色块、霓虹光晕、玻璃拟态或高饱和强调色。
- 标题与数字使用有辨识度的几何字体，标签与参数使用等宽字体。

## 工作台结构

界面由四个区域组成：

1. 顶部状态栏：产品名、当前组件编号、1920×1080、循环状态。
2. 左侧组件栏：三个带动态微缩预览的组件入口。
3. 中间预览舞台：逻辑尺寸固定为 1920×1080，按容器等比缩放；展示安全区和画布状态。
4. 右侧参数栏：当前组件参数、恢复默认、重新播放。

窗口缩小时保持三栏结构到合理桌面宽度；更窄时允许页面横向保持最小工作区宽度，不把专业工作台强行折叠成移动端卡片。

## 人物口播构图修订

预览舞台使用用户提供的横版人物参考图作为默认背景。人物位于中间偏右，因此动效采用不对称的“左主右辅”布局，而不是占满整个画面。

- 人物安全区约为画面横向 `39%–86%`、纵向 `6%–95%`。
- 左侧主动效区约为 `4%–35%`，承载核心数字、对比主卡或金句。
- 右侧辅助区约为 `87%–97%`，只承载短趋势、结果数字、状态或署名。
- 任何文字、数字、卡片、扫描线和连接线都不得进入人物安全区。
- 安全区辅助线默认显示，可在右侧参数栏关闭；关闭只隐藏标记，不改变组件避让规则。
- 视频背景上的信息区使用半透明深色底和细边界增强可读性，不使用重阴影或大面积彩色装饰。

三个组件按人物构图重新布局：

- MetricFocus：左侧核心指标主卡，右侧趋势与锁定状态。
- CompareSplit：左侧 Before 主卡，右侧 After 窄型结果卡；结论位于左侧底部。
- QuoteLockup：左侧金句，右侧署名与身份标签。

## 播放与数据流

- 当前组件及其参数由工作台持有。
- 组件只接收类型明确的参数和 `playbackKey`，不读取右侧面板状态。
- 切换组件、修改参数或点击“重新播放”都会更新 `playbackKey`，使动效从头开始。
- 动效进入后自动播放并无限循环，不提供时间轴、暂停或进度拖动。
- “恢复默认”只重置当前组件参数。
- 文本输入设置合理长度限制；数值滑块和输入框都受最小值、最大值约束。

## 三个动效组件

### MetricFocus

用于突出单个核心指标。

- 内容：眉题、核心数值、前缀、后缀、说明、趋势文本。
- 参数：数值、前后缀、标签文本、趋势文本、动画时长、小数位数。
- 动效：框线扫描进入，数字从零计数，单位与趋势分层错峰出现，最后以短暂刻度脉冲锁定。
- 默认示例：`+248%`，`QUARTERLY GROWTH`。

### CompareSplit

用于左右两组数据或观点的直接对比。

- 内容：总标题、左侧标签与数值、右侧标签与数值、底部结论。
- 参数：双方文本与数值、强调侧、分割线位置、动画时长。
- 动效：中央分割线切入，两侧面板反向展开，数值错峰计数，强调侧以边界和明度完成锁定。
- 默认示例：`Before / After`，`42% / 86%`。

### QuoteLockup

用于金句、观点或结论定格。

- 内容：眉题、引文、署名、身份说明。
- 参数：各段文本、文本对齐、最大行宽、动画时长。
- 动效：定位标记与基线先出现，引文按行错峰显现，关键词短暂提升明度，署名最后进入并定格。
- 默认示例使用简短中文金句，验证中英文混排能力。

## 组件与配置边界

- 每个动效拥有独立的类型、默认参数、预览组件和参数面板配置。
- 组件注册表负责把组件 ID、名称、编号、默认值和渲染器组合起来。
- 通用参数控件只处理文本、数值、范围、选择和分段按钮。
- 动效内部可共享计数器、分层显现、辅助线等基础能力，但不建立过度抽象的“万能动画引擎”。

## 可访问性与降级

- 所有参数控件有可读标签，按钮支持键盘焦点。
- 左侧组件入口使用真实按钮，并暴露当前选中状态。
- 尊重 `prefers-reduced-motion`：关闭循环位移动画，直接显示最终状态。
- 字体加载失败时回退到可靠的中文和等宽字体栈。

## 错误与边界处理

- 非法数值在进入组件前夹紧到参数范围。
- 空文本显示短占位符，避免布局坍塌。
- 超长文本在参数层限制长度；QuoteLockup 额外限制可用宽度并控制换行。
- 未知组件 ID 回退到 MetricFocus。

## 技术方案

- React、TypeScript、Vite。
- Motion for React 负责组件编排与入场动画。
- CSS Variables 管理色彩、边界、字体、间距和舞台比例。
- Vitest + React Testing Library 覆盖注册表、参数变更、重播和关键组件内容。
- ESLint、TypeScript 构建和 Vite build 作为静态验收。

## 验收标准

- 首屏呈现三栏预览台，默认选中 MetricFocus。
- 中间舞台始终保持 16:9，逻辑尺寸清晰标注为 1920×1080。
- 舞台默认显示人物参考图和安全区标记，安全区可隐藏。
- 三个组件的主要和辅助信息分别约束在左侧与右侧区域，不覆盖人物。
- 三个组件均可切换、循环播放、重新播放并实时调整参数。
- 恢复默认只影响当前组件。
- 页面不存在 Remotion、ffmpeg、导出、时间轴或素材管理入口。
- 黑白灰占绝对主导，无明显彩色渐变和重阴影。
- 自动化测试、TypeScript 检查、Lint 与生产构建通过。
- 在桌面浏览器中完成视觉检查，无明显溢出、遮挡或控制面板错位。
