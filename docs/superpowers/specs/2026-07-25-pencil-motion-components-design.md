# 手绘铅笔动效组件设计

## 目标

将现有六个短视频动效组件统一重做为“黑纸银铅”手绘风格。新视觉需要保留当前横版口播视频的空间约束：人物位于画面中间偏右，动效主要分布在左侧与人物两边，不能进入人物安全区，底部必须完整保留 150px 字幕安全区。

本次只修改动效组件的视觉与入场表现，不改变预览台的信息架构、参数编辑能力、组件数据结构或内部英文标识。

## 已确认的设计方向

- 风格：黑纸银铅。
- 容器：开放线稿，不使用厚重的完整卡片。
- 动效：混合式节奏。结构平滑进入，关键线条逐笔绘制，最后带极轻微的手绘呼吸感。
- 色彩：银白、石墨灰、透明黑为主，不增加常规彩色强调。
- 层级：用字号、线宽、留白、排线密度和擦除程度制造重点。
- 质感：少阴影，不使用玻璃拟态；通过铅笔纹理、双线、擦痕和不完全笔触建立高级手绘感。

## 共用视觉语言

### 开放式线稿

每个组件只使用局部半透明黑底、单侧边线、短基线或不闭合的角标，不再绘制完整矩形外框。线条需要保留轻微的不规则感，但不能抖动到影响阅读。

### 铅笔纹理

线条由两层构成：一层稳定的主线保证清晰度，一层低透明度纹理模拟石墨颗粒。填充区域使用稀疏斜向排线或擦除残影，不使用纯色大面积填充。

### 字体层级

- 核心数字和关键结论使用现有高可读字体，保持稳定、清晰。
- 标签、批注、步骤说明使用中文手写感字体栈。
- 不依赖字体本身制造全部手绘感，关键质感由线条、排线和动效承担，避免字体不可用时视觉失效。

### 动效节奏

每个组件遵循相同的四段式节奏：

1. 开放式结构和文字以平滑位移、透明度变化进入。
2. 基线、箭头、环线或路径使用逐笔绘制效果出现。
3. 核心数字、最高柱或当前步骤完成强调并定格。
4. 仅装饰线保持 1–2px 的极轻呼吸；正文和数字不持续抖动。

组件仍然使用现有循环预览和可调动画时长。用户点击“重新播放”后，从第一段重新开始。

## 六个组件

### 1. 核心指标

- 左侧保留一个不闭合的铅笔坐标结构。
- 核心数字是最大视觉元素，稳定计数进入。
- 数字下方基线逐笔画出，趋势箭头随后出现。
- 趋势说明作为小号手写批注收尾。

### 2. 对比卡片

- 去掉左右两张厚卡，改为同一开放结构内的两组数字。
- 旧值先出现，再由一条手绘线划除。
- 新值通过更大字号和更粗下划线建立优势。
- 结论使用手绘箭头连接两个数值，不使用彩色胜负标识。

### 3. 人物信息

- 姓名或身份作为手稿标题出现。
- 三条事实逐句写入，并在每条完成后绘制方框勾选。
- 信息层级通过首行字号、事实间距和勾选框线宽区分。
- 保留现有逐句出现逻辑，不增加人物照片或额外媒体。

### 4. 柱状对比

- 柱体轮廓逐个向上绘制，内部使用稀疏铅笔排线。
- 数据仍然按当前归一化逻辑控制柱高。
- 最高柱只通过高度、轮廓加粗和更密排线强调。
- 标签与结论保持在柱体下方和侧边，不进入字幕安全区。

### 5. 环形占比

- 环线从顶部开始逐笔绘制。
- 主要占比使用清晰双线，次要占比退为低透明度擦除残影。
- 中心数字稳定缩放进入，不跟随环线抖动。
- 图例使用线段长度和文字大小区分，不引入多色图例。

### 6. 五步流程

- 五个步骤沿一条略带手绘弧度的路径依次出现。
- 已完成步骤保留浅色轨迹，未到达步骤降低透明度。
- 当前步骤使用更大的方框和双描边强调。
- 步骤标题逐句显示，继续保留五步参数编辑能力。

## 空间与安全约束

- 所有核心内容必须保持在人物安全区之外。
- 装饰性铅笔线可以靠近安全区边缘，但不能穿过人物面部或躯干区域。
- 画布底部 150px 不放置图形、说明、标签或持续动画。
- 小屏预览只等比缩放 1920×1080 设计，不改变组件内部布局逻辑。

## 技术边界

- 保留现有六个组件文件、注册表、属性类型和参数面板。
- 使用 CSS、SVG 和现有 React 动效能力完成效果。
- 不接入 Remotion、ffmpeg、视频导出、Canvas 绘图引擎或新的重型动画依赖。
- 可以新增共享的铅笔纹理、逐笔线条和开放框样式组件，减少六个组件之间的重复。

## 测试与验收

- 六个组件原有数据与交互测试继续通过。
- 新增共享手绘视觉标记和关键结构的组件测试。
- 验证所有组件在重播后能重新执行四段式动效。
- 浏览器逐一检查六个组件，确认人物安全区与底部 150px 字幕区没有被侵入。
- 在 1920×1080 设计比例下确认文字清晰、无截断、无横向溢出。
- 页面仍保持全中文操作界面。
