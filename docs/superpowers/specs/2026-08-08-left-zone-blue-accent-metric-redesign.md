# 左侧内容区、深蓝辅助色与核心指标重设计

## 目标

在不改变 Overlay Studio 黑白灰主体、字体、时间轴、参数模型和导出规格的前提下，完成三项视觉升级：

1. 采用用户选择的 A「轴线读数」方案重做第二张“核心指标”。
2. 为全部七种动效增加统一深蓝辅助色。
3. 所有动效只在视频左侧约 60% 区域呈现，视频右侧约 40% 始终留空。

## 已确认的视觉方向

- 继续使用 Precision Monolith：黑色画布、冷白主信息、灰色次信息、工程网格和克制的技术感。
- 深蓝是辅助色，不取代黑白灰主色。统一基准色为 `#2f67b2`，暗部与透明状态由该颜色派生。
- 深蓝用于英文眉题、序号、步骤数字、重点刻度、活动状态和少量数据强调；大面积正文、主体数字与背景仍以冷白、灰、黑为主。
- 不在视频右侧保留状态栏、结果栏、轨道栏或其他视觉信息。
- 对比卡片保留两组对比数据，但两组数据都压缩并重排到左侧内容区，不删除对比语义。

## 统一画面区域

所有 React 预览和 Canvas/Worker 导出使用相同空间合同：

- 左侧内容区：画布宽度的约 58%–62%。
- 右侧留白区：画布宽度的约 38%–42%，不绘制文字、数字、面板、线条或装饰。
- 背景网格和全画布纹理可以继续存在；它们不属于“右侧内容”。
- 现有字幕安全区高度约束继续有效。

各动效的处理方式：

- 叙述：保持左侧两行大字与小字结构，只把英文眉题和短线改为深蓝。
- 核心指标：使用新的轴线读数布局，并删除原右侧趋势状态栏。
- 对比卡片：左右两组数据并排或上下组合在左侧内容区内；结论收进左侧底部，不跨入右侧留白区。
- 人物信息：删除右侧轨道状态栏，左侧人物信息卡保持原信息层级。
- 柱状对比：删除右侧结果栏，柱状图在左侧内容区内完成表达。
- 环形占比：删除右侧结果栏，环图与图例限制在左侧内容区。
- 步骤流程：删除右侧状态栏，步骤数字与流程线限制在左侧内容区。

参数字段和 JSON 兼容性保持不变。暂时不再显示的右侧辅助字段仍可被导入、编辑和保存，避免破坏已有项目文件。

## 核心指标：A「轴线读数」

核心指标不再使用旧的“左侧数字 + 右侧状态栏”构图，改为单一左侧读数系统：

- 顶部：深蓝英文眉题与 `02` 序号，例如 `QUARTERLY GROWTH / 02`。
- 中部：冷白超大数值作为唯一视觉中心；前缀或单位可使用深蓝，但不能压过主体数字。
- 数值下方：一条水平轴线，前段深蓝、后段灰色并渐隐。
- 轴线下方：一组稀疏深蓝刻度，随动画依次出现。
- 底部：一行简短说明文字；趋势参数可作为说明的补充，但不再单独占据右侧面板。
- 动画：保留数字计数、模糊到清晰和轴线绘制；删除旧右侧面板进入动画和无意义的全宽扫描装饰。

React 与 Canvas renderer 必须使用相同布局、颜色、动画时序和留白边界。

## 深蓝辅助色系统

浏览器 CSS 新增统一变量：

- `--motion-accent-blue: #2f67b2`
- `--motion-accent-blue-muted: rgba(47, 103, 178, .42)`
- `--motion-accent-blue-faint: rgba(47, 103, 178, .16)`

Canvas 新增对应的 `CANVAS_COLORS.accentBlue`、`accentBlueMuted`。禁止在各 renderer 中继续散落多个不一致的蓝色色值。

建议映射：

- 英文眉题、编号：基准深蓝。
- 步骤数字、活动步骤圆环：基准深蓝；非活动状态继续用灰色。
- 柱状图重点柱、环形图重点弧段：深蓝；其余数据保持灰阶。
- 人物信息勾选标记与短强调线：深蓝。
- 对比卡片被强调的一组：深蓝刻度或下划线，主体数据仍为冷白。

## 代码边界

- `src/styles.css`：统一蓝色变量、左侧内容区规则、核心指标新布局和七种动效的蓝色映射。
- `src/motion/MetricFocus.tsx`：重建 A 方案结构，移除右侧状态栏节点。
- `src/motion/CompareSplit.tsx`：把两组对比和结论限制在左侧区域。
- `src/motion/ProfileReveal.tsx`、`BarCompare.tsx`、`ShareRing.tsx`、`StepFlow.tsx`：删除右侧辅助节点。
- `src/motion/canvas/*Renderer.ts`：同步左侧区域、删除右侧绘制、应用统一蓝色。
- `src/export/canvas/primitives.ts`：增加 Canvas 深蓝色常量。
- 对应 React、状态和 Canvas 测试：验证右侧节点消失、内容边界和蓝色语义。

## 验证

- 组件测试确认所有旧 `right-secondary` 节点和右侧测试节点不再渲染。
- 对比卡片测试确认两组数据仍存在，且都属于左侧内容区。
- 核心指标测试确认 A 方案的英文眉题、主数值、轴线和刻度结构存在，旧右侧状态栏不存在。
- Canvas 单元测试确认不再在右侧坐标区域绘制文字、面板和线条。
- 页面检查七种动效的右侧区域为空，深蓝色只承担辅助强调。
- Canvas/React 对照检查核心指标布局和颜色一致。
- 执行完整测试、ESLint、生产构建和 `git diff --check`。

## 范围外

- 不改变参数表单和项目 JSON Schema。
- 不改变视频播放控制条、字幕安全区、编辑器选中框和时间轴片段。
- 不改变 Noto Sans SC 字体方案。
- 不改变透明导出分辨率、帧率、编码器或 Alpha 合同。
