# 桌面“展示台”启动脚本设计

## 目标

在 Windows 桌面创建 `展示台.bat`。用户双击后即可启动 Overlay Studio 本地服务，并自动在默认浏览器打开工作台。

## 实现方案

桌面脚本不重复实现 Node.js 检查、构建、端口选择和浏览器启动逻辑，而是调用项目中已有的 `E:\Code\Motion-playground\启动 Overlay Studio.bat`。

这样可以继续复用现有启动器的以下能力：

- 自动检查 Node.js 和 npm。
- 自动安装缺失依赖并构建最新版网页。
- 自动检测或选择 `4173` 至 `4192` 范围内的可用端口。
- 明确输出启动成功状态和实际访问地址。
- 自动打开系统默认浏览器。
- 服务运行期间保持控制台进程。

## 桌面脚本行为

1. 切换控制台为 UTF-8，并设置标题为“Overlay Studio 展示台”。
2. 检查项目启动脚本是否存在；不存在时显示完整项目路径和失败原因。
3. 调用项目启动脚本，并保留其全部构建、端口和成功信息。
4. 当启动器返回时，显示退出状态。
5. 无论成功结束还是失败，执行 `pause`，避免控制台窗口自动消失。

## 错误处理

- 项目路径不存在：显示“找不到 Overlay Studio 项目启动器”。
- Node.js、npm、依赖安装或构建失败：直接保留现有启动器输出，并显示失败退出码。
- 浏览器自动打开失败：现有启动器会显示可手动访问的本地网址。

## 验收方式

- 确认桌面存在 `展示台.bat`。
- 在没有服务运行时启动，确认控制台显示实际端口、启动成功，并能访问状态接口。
- 在服务已经运行时再次启动，确认能识别现有实例、显示其端口并重新打开浏览器。
- 确认启动结束或失败后控制台停留在 `pause` 提示，不会直接消失。

## 范围限制

- 不修改 Overlay Studio 的项目结构。
- 不新增桌面框架或额外依赖。
- 桌面脚本固定指向 `E:\Code\Motion-playground`；如果项目以后移动，需要同步修改该路径。
