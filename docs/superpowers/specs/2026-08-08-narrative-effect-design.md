# “叙述”动效设计

## 目标

在 Overlay Studio 的动效组件库中新增“叙述”效果，用两排大字概括视频当前内容，并在大字下方提供一行小字解释。效果只占用画面左侧，右侧保持完全留空，便于保留人物或主体画面。

## 已确认的视觉方向

- 使用用户选择的 B 布局：文字组锚定画面左上区域。
- 使用用户选择的 A 动效：第一排大字、第二排大字、分隔线、小字依次显现。
- 延续项目现有 Precision Monolith 视觉语言：冷黑底色、冷白大字、细网格、低彩度辅助文字、克制阴影。
- 不在右侧添加编号、轨道、卡片、图标或其他装饰信息。

## 组件注册与参数

新动效 ID 为 `narrative`，名称为“叙述”，放在 `motionRegistry` 第一位并使用编号 `01`。现有六个效果顺延为 `02` 至 `07`，组件库底部计数更新为 7 个组件。

可编辑参数：

- `line1`：第一排大字，最多 12 个字符。
- `line2`：第二排大字，最多 12 个字符。
- `explanation`：下方小字解释，最多 32 个字符。
- `duration`：完整循环时长，范围 3.2–8 秒。

默认示例为“把复杂的工作 / 交给自动化”，解释为“让系统处理重复步骤，人只负责判断与创造。”。空字符串使用对应默认占位，避免布局塌陷。

## 画面结构

内容组位于 1920×1080 画布左侧约 `x=130–850`、`y=190–620` 的范围内：

1. 顶部显示小号等宽眉题 `NARRATIVE / 01`。
2. 两排冷白大字左对齐，形成最强信息层级。
3. 大字下方绘制一条短横线。
4. 横线下方显示低亮度小字解释。
5. 画面右侧不渲染任何叙述组件内容。

组件继续使用项目统一的透明动效画布与背景网格；导出时只输出动效卡层，不引入源视频。

## 动效节奏

完整循环按参数 `duration` 进行采样：

- 第一排大字在循环开始后上浮并去模糊显现。
- 第二排大字稍晚进入，保持清晰的逐层叙述感。
- 短横线从左向右绘制。
- 小字解释最后轻微上浮淡入。
- 所有内容稳定停留，循环末尾统一淡出。
- `prefers-reduced-motion` 下直接显示最终静态状态。

React 预览和 Canvas 导出共用同一套时间状态函数，避免浏览器预览与 PNG/MOV 导出节奏漂移。

## 文件边界

- `src/motion/Narrative.tsx`：React 结构和 Motion 动画绑定。
- `src/motion/canvas/narrativeState.ts`：可确定采样的分层透明度、位移和横线进度。
- `src/motion/canvas/narrativeRenderer.ts`：1920×1080 Canvas 绘制。
- `src/motion/types.ts`：`NarrativeParams` 和 `narrative` ID。
- `src/motion/registry.ts`：组件默认值、控件和首位注册。
- `src/export/canvas/rendererRegistry.ts`：Worker 安全 Canvas 注册。
- `src/styles.css`：左上叙述布局和组件库缩略图。

## 容错与兼容

- 空文字回退到默认占位；超长输入由控件 `maxLength` 限制。
- 时长在状态函数中钳制，导入旧项目或手工 JSON 时仍可安全渲染。
- `MotionId`、Canvas renderer registry、视觉夹具均同步加入新 ID，保证导出覆盖完整。
- 不改变现有项目文件格式；旧项目仍可正常载入。

## 验证

- 注册测试：确认 `narrative` 是第一个 ID，名称和编号正确，现有效果编号顺延。
- React 测试：确认两排大字、小字、左侧主区域和右侧无内容；空值回退正确。
- 状态测试：确认四层内容按顺序进入、稳定停留并在循环末尾淡出。
- Canvas 测试：确认 renderer 注册完整并只在左侧坐标范围绘制文字。
- 工作台测试：确认列表中可选择并添加“叙述”，组件总数显示为 7。
- 完整执行 `npm test -- --run`、`npm run lint`、`npm run build` 和 `git diff --check`。

## 范围外

- 不增加右侧内容、图片、人物卡或数据图形。
- 不增加自动拆句、AI 文案生成或字幕解析逻辑。
- 不改变透明导出的分辨率、帧率或编码流程。
