# 对比卡片人物安全区重设计

## 背景

当前“对比卡片”采用横向双面板。两组数据、中央箭头和底部结论共同占据较宽画面，实际右缘进入 `39%` 人物保护线，遮挡口播人物。现有设计也把“左右位置”当作对比语义的一部分，导致简单缩窄后数字、标签和结论都会拥挤。

本次重做选择 A「双层数据轨」：把两组数据改为上下排列，在不减少信息的前提下，将全部内容限制在视频左侧人物安全区之外。

## 目标

- 对比卡片全部视觉内容严格位于人物保护线左侧。
- 保留标题、两组标签与数值、后缀、强调状态和结论。
- 通过上下层级表达“基准数据 → 结果数据”，不再依赖横向双面板。
- 保持现有项目数据、参数字段和导出注册兼容。
- React 预览与 Canvas 导出使用相同的布局边界和动画时间状态。

## 非目标

- 不新增第三组对比数据。
- 不修改人物保护线位置。
- 不改变对比卡片的 motion id、参数字段或持久化结构。
- 不重做柱状对比等其他动效。

## 版式

卡片采用固定的左侧内容区：

- `left: 6.35%`
- `width: 31.8%`
- 右缘为 `38.15%`
- 人物保护线为 `39%`

卡片从上到下分为四层：

1. 英文/编号眉题与对比标题。
2. 上排基准数据轨。
3. 下排结果数据轨。
4. 底部结论。

上、下数据轨等宽排列。每条数据轨包含小号语义标签、大号数值、后缀和一条进度刻度。上排默认使用中性灰色和较低对比度；下排默认使用冷白大字，并通过深蓝色编号、刻度和底线强调。若用户选择强调上排，则两排的强调层级互换。

删除原有横向双面板、横向中央箭头和所有跨入人物区域的装饰。视频右侧不显示对比卡片内容。

## 参数兼容

保留现有 `CompareSplitParams`：

- `title`：对比标题。
- `leftLabel`、`leftValue`：上排基准标签与数值。
- `rightLabel`、`rightValue`：下排结果标签与数值。
- `suffix`：两组数值共用后缀。
- `conclusion`：底部结论。
- `emphasis`：内部仍保存 `left | right`，界面文案改为“强调上排 / 强调下排”。
- `split`：内部字段保持不变，改为控制数据轨内容区内的纵向分割位置；沿用现有 `32%–68%` 范围，默认 `50%`，两条数据轨始终保持在面板内。
- `duration`：动画时长。

参数面板中的“左侧标签/数值”“右侧标签/数值”分别改为“基准标签/数值”“结果标签/数值”。旧工作区无需迁移，载入后直接按新布局渲染。

空标题、标签或结论继续使用现有默认文案。文本仍遵守注册表中的最大长度，布局不得因边界长度输入越过卡片范围。

## 动画

动画顺序如下：

1. 眉题和标题淡入，并从左侧轻微上移。
2. 上排数据轨出现，数值从 0 递增到基准值。
3. 深蓝色扫描线由上向下移动，连接两种状态。
4. 下排数据轨展开，数值递增到结果值，并执行一次克制的蓝色高亮。
5. 底部结论最后淡入并保持稳定。
6. 循环退出时整体淡出。

高亮不持续呼吸、不重复闪烁。开启减少动态效果时，直接显示最终数值、最终强调状态和结论。

React 和 Canvas 必须共用确定性的状态采样逻辑，至少覆盖标题、上下轨透明度、扫描线进度、两个数值进度、强调高亮和结论透明度。

## Canvas 导出

Canvas 采用与 CSS 相同的 1920×1080 布局契约。人物保护线为 `x = 748.8`，所有对比卡片绘制终点必须小于该值。卡片面板与步骤卡和投票卡共用左侧安全边界：面板右缘固定为 `x = 732`，为保护线保留明确间隔。

Canvas 不绘制原横向双面板和中央箭头。两条数据轨、扫描线和结论都在同一左侧面板内完成。

## 可访问性与降级

- React 保持两个语义化数据区域，并使用稳定的测试标记区分基准与结果。
- 强调状态不能仅依赖颜色，同时通过字重、透明度和刻度粗细表达。
- 减少动态效果时不隐藏任何核心信息。
- 空文本使用默认值；边界文本不得产生横向滚动或人物区溢出。

## 测试与验收

自动化验证必须覆盖：

- CSS 卡片右缘为 `38.15%`，严格小于 `39%` 人物保护线。
- Canvas 所有主要绘制终点小于 `x = 748.8`，面板右缘固定为 `x = 732`。
- 两条数据轨均存在，并在 DOM 和 Canvas 中按上下顺序排列。
- `left` 与 `right` 强调值分别正确映射到上排与下排。
- 数值递增、扫描线、一次高亮、结论入场和退出状态正确。
- 减少动态效果直接显示稳定最终状态。
- 旧参数对象、项目持久化、组件注册和 Canvas 导出注册保持兼容。
- 标题、标签、后缀和结论的边界长度不会溢出。

浏览器验收必须确认：

- 对比卡片不进入人物保护线。
- 七成以上视觉重量集中在两条数据轨，标题和结论层级清晰。
- 视频右侧无任何对比卡片内容。
- 上下强调切换、纵向分割位置和重新播放均生效。
- 页面无水平/垂直异常滚动条，控制台无错误或警告。
