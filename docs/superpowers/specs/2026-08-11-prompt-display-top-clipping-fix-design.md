# AI 提示词卡片首行顶部裁切修复设计

## 问题

`prompt-display` 正文裁切区域从 `CONTENT.y` 开始，第一行文字也绘制在同一个 `CONTENT.y`。第一行顶部没有安全空间，部分中文字体的顶部笔画、抗锯齿边缘或重点词光晕会落在裁切区域之外，形成顶部笔画被遮挡的现象。

## 修复方案

在正文裁切区域内增加固定的 `8px` 顶部安全间距：

- 裁切矩形和卡片整体位置保持不变。
- 第一行文字从 `CONTENT.y + 8` 开始绘制。
- 后续行继续按现有 `LINE_HEIGHT` 排列。
- 打字机光标使用同一垂直偏移。
- 自动滚动仍按行高计算，不改变触发时机和滚动速度。

## 保持不变

- 字号与字重。
- 行高和正文宽度。
- 重点词蓝色效果。
- 换行和字形揭示顺序。
- 提示词开始、打字、停留和退出时间。
- 卡片位置、尺寸与字幕安全区。

## 验证

增加渲染器回归测试，记录正文裁切顶部与第一行文字的绘制坐标，确认第一行文字和光标的 `y` 坐标至少比裁切顶部大 `8px`。同时运行提示词布局、状态、渲染器及完整项目测试，确认自动滚动和现有视觉契约不受影响。
