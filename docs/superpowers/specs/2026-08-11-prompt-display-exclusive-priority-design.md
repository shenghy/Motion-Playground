# 字幕特效 Skill：提示词展示排他优先级设计

## 目标

修改已安装的 `subtitle-effects` Skill。当字幕包含完整 AI 提示词时，优先生成一张 `prompt-display`，并禁止在该提示词的完整展示区间内增加或保留其他动效卡片。

## 优先级规则

AI 提示词在语义筛选阶段拥有最高优先级：

1. 第一轮先扫描并确定全部完整 AI 提示词语义组。
2. 每个提示词语义组只生成一张 `prompt-display`。
3. 提示词即使同时包含数字、步骤、对比、人物、结论或互动问句，也不得再生成其他组件。
4. 提示词前后不属于该提示词的字幕仍按现有规则选择其他动效。

## 排他时间范围

排他范围从提示词首条字幕的 `start` 开始，到 `prompt-display` 卡片最终 `end` 结束。该 `end` 已包含末条字幕结束后的 `holdDuration` 与 `exitDuration`。

任何其他卡片只要与该区间发生时间重叠，就必须删除或不生成。不得通过缩短、后移或改变提示词卡片时间来保留其他卡片。

## 工作流程调整

语义分析改为以下顺序：

1. 建立字幕时间轴和可选文章上下文地图。
2. 优先识别完整 AI 提示词并计算全部排他区间。
3. 在剩余字幕区间中扫描其他高价值语义组。
4. 生成其他卡片前检查是否与任一提示词排他区间重叠。
5. 最终复核再次删除所有与 `prompt-display` 重叠的非提示词卡片。

## JSON 契约

不增加新的 JSON 字段，也不修改 Overlay Studio 九组件 schema。排他优先级属于生成阶段的语义规则，通过 Skill 文档和契约测试保证。

## 验证

在 `scripts/test_tools.py` 中增加文档契约测试，确认 Skill 明确包含：

- AI 提示词最高优先级。
- 每个提示词只生成一张 `prompt-display`。
- 提示词区间内不生成其他特效。
- 排他区间包含停留和退出时间。
- 最终复核删除所有重叠的非提示词卡片。
- 提示词前后的无关字幕仍可使用其他特效。
