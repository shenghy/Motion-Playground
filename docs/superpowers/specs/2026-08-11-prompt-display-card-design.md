# “提示词展示”卡片设计

## 目标

为 Overlay Studio 新增卡片效果“提示词展示”，用于在口播视频中清晰呈现 AI 提示词。卡片采用左侧均衡布局，以大字号逐字显示完整提示词，自动标蓝重点词；内容超出可视区域时按行向上滚动。卡片时间、提示词、重点词和停留时间均写入 Overlay Studio JSON，并由 `subtitle-effects` 技能根据字幕自动生成。

## 已确认范围

- 新增 `prompt-display` 动效及其 Canvas/Worker 透明导出实现。
- 新增长文本、多行参数编辑能力，让卡片仍可在 Overlay Studio 中手动修正。
- 更新 `subtitle-effects` 技能的组件参考、语义选择、JSON 生成和校验规则。
- 以一份真实 SRT 完成自动生成、JSON 校验、项目解析和浏览器视觉检查。
- 不引入运行时大模型调用。重点词分析发生在 `subtitle-effects` 生成 JSON 的阶段，渲染器只执行 JSON 中的确定性结果。
- 不改变 1920×1080、底部字幕安全区和透明 ProRes 导出合同。

## 视觉设计

采用已确认的 A 方案“左侧均衡卡片”：卡片位于画面左侧，避开中间偏右的人物区域，并完整保留底部字幕安全区。

- 1080p 画布正文目标字号为 40–46px，优先保证观众可读性。
- 卡片为深色半透明底，保持现有冷白、克制、无厚重外框的视觉语言。
- 顶部使用小型眉题，例如 `AI PROMPT / 01`。
- 正文使用清晰的等宽或近等宽字体。
- 重点词使用蓝色字体和轻微蓝色辉光，不使用遮挡正文的大面积色块。
- 打字光标使用同一蓝色，打字结束后隐藏。

## 动画节奏

动画分为进入、打字、溢出滚动、完整停留和退出五个阶段。

1. 对应提示词字幕开始时，卡片轻微淡入并上移，第一个字同时出现。
2. 文字在有效字幕时间内连续打出，最后一个字必须在对应字幕结束时出现。
3. 新行即将超出卡片可视区时，内容短促、平滑地上滚一行；不做持续漂移，光标始终保留在可视区。
4. 打字结束后停止滚动并隐藏光标，完整画面停留 1–3 秒。
5. 停留末尾快速淡出，随后卡片消失。

停留时间按提示词长度自动选择，并写入 JSON：

- 40 字以内：1 秒。
- 41–100 字：2 秒。
- 100 字以上：3 秒。

## JSON 合同

动效 ID 为 `prompt-display`。单张卡片保存完整提示词，不按字幕逐条拆成多张卡片。建议结构如下：

```json
{
  "id": "prompt-001",
  "motionId": "prompt-display",
  "start": 12.4,
  "end": 24.8,
  "position": { "x": 0, "y": 0 },
  "zIndex": 3,
  "params": {
    "eyebrow": "AI PROMPT / 01",
    "prompt": "请生成一张电影级写实的数据中心画面……",
    "keywords": "电影级写实|冷暖光线对比|真实金属材质",
    "holdDuration": 2,
    "exitDuration": 0.18
  }
}
```

字段语义：

- `start`：提示词对应字幕的开始时间。
- 对应字幕结束时间：`end - holdDuration - exitDuration`。
- `end`：对应字幕结束时间加 `holdDuration` 和 `exitDuration`。
- `eyebrow`：卡片眉题。
- `prompt`：完整提示词原文。
- `keywords`：以 `|` 分隔的重点词，只允许引用 `prompt` 中实际存在的文字。
- `holdDuration`：完整静止阅读时间，为 1、2 或 3 秒。
- `exitDuration`：退出淡出时间，默认为 0.18 秒，允许范围为 0.1–0.3 秒。

渲染器通过 `end - start - holdDuration - exitDuration` 推导打字阶段。JSON 中的时间为唯一真相，预览、时间轴跳转和透明导出不得使用独立计时器。

## 重点词分析

`subtitle-effects` 在生成 JSON 时分析提示词原文，优先提取：

- 主体与对象。
- 关键动作。
- 风格与质量要求。
- 镜头和运动。
- 光线、色彩与材质。
- 重要构图或限制条件。

技能不得补写原文之外的词。重复出现的重点词全部标蓝；重叠关键词优先匹配更长者。关键词为空时卡片仍可正常显示。未在原文中命中的关键词由校验器报告警告，并在渲染时安全忽略。

## 自动生成流程

1. 解析 SRT，并识别连续字幕是否共同构成完整 AI 提示词。
2. 合并该提示词对应的连续字幕，保留第一条开始时间和最后一条结束时间。
3. 从合并后的原文提取重点词，不引入字幕之外的信息。
4. 根据提示词长度选择 1、2 或 3 秒停留时间。
5. 生成一张 `prompt-display` 卡片，写入完整参数、`start` 和包含停留与退出时间的 `end`。
6. 使用更新后的技能校验器验证 JSON；修复错误后再交付。
7. 使用 Overlay Studio 当前项目解析器做兼容性验证。

## 代码边界

实现保持布局、时间状态和绘制职责分离：

- `promptDisplayLayout`：按真实字体测量换行，计算字符单元、关键词范围、可见行和目标滚动位置。
- `promptDisplayState`：根据当前本地时间和卡片总时长计算已显示字符数、光标状态、滚动进度和退出透明度。
- `promptDisplayRenderer`：按已计算结果绘制卡片、眉题、正文、重点词和光标。

状态计算必须是纯函数，不依赖上一帧。任意时间点都应能单独重建同一画面，以保证拖动时间轴、逐帧导出和 Worker 导出结果一致。

长提示词编辑需要扩展现有参数控件，增加多行文本控件。参数类型仍保持 JSON 可序列化，`keywords` 使用分隔字符串，避免引入嵌套时间数组和新的项目版本。

## 文本与滚动规则

- 使用实际 Canvas 字体测量换行，不按固定字符数粗略断行。
- 按 Unicode 字素簇逐字显示，不能拆开 Emoji、变体选择符或组合字符。
- 优先保持 40–46px 字号；文本过长时通过滚动处理，不缩成难以阅读的小字。
- 滚动目标由当前已显示行数确定，并在短时间内平滑过渡到下一行位置。
- 滚动计算不得依赖累积帧状态，跳转到相同时间必须得到相同位置。
- 打字完成后停在最终阅读位置，不反向滚回顶部。

## 错误处理

- `prompt` 为空：技能校验失败，不生成空卡片。
- `holdDuration` 不是 1、2 或 3：技能校验失败；渲染器仍将异常值安全限制在 1–3 秒。
- `exitDuration` 不在 0.1–0.3 秒：技能校验失败；渲染器使用 0.18 秒安全默认值。
- `keywords` 为空：合法，不显示蓝色重点词。
- 关键词未命中原文：校验器警告，渲染器忽略。
- 关键词重叠：优先较长匹配，避免重复绘制。
- 提示词超长：继续滚动，不截断正文、不降低到不可读字号。
- 时间不足以形成正打字阶段：校验失败；渲染器在异常输入下退化为立即显示完整提示词并按安全停留时间结束。

## 验证计划

- 状态单元测试：开始、打字中、字幕结束、停留中和消失边界。
- 排版单元测试：中文、英文、数字、标点、显式换行、Emoji 和超长提示词。
- 重点词测试：重复、重叠、未命中和空关键词。
- 滚动测试：仅在溢出时触发、每次按行移动、光标始终可见、任意时间跳转结果确定。
- 安全区域测试：卡片、正文和滚动内容不进入人物区域与底部字幕区。
- 注册表和导出测试：动效 ID、默认参数、Canvas 注册表、视觉夹具和 Worker 透明导出覆盖完整。
- JSON 兼容测试：新卡片可被当前项目保存、导入、解析和再次导出。
- 技能前向测试：真实 SRT 自动生成一张完整提示词卡片，重点词和时间正确，技能校验器通过。
- 全量验证：运行相关单测、完整测试、类型构建、代码检查和浏览器视觉检查。

## 非目标

- 不在 Overlay Studio 运行时调用 AI 服务分析重点词。
- 不为每一条普通字幕机械生成提示词卡片。
- 不将一个完整提示词拆成多张连续卡片。
- 不新增结构化字幕分段时间数组。
- 不改变透明视频编码、分辨率、帧率或 Alpha 合成合同。
