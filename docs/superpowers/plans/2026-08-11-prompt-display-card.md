# Prompt Display Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a deterministic `prompt-display` motion card that types a complete AI prompt to subtitle timing, highlights JSON-specified keywords in blue, scrolls overflowing lines upward, holds for 1–3 seconds, fades out, and can be generated by the installed `subtitle-effects` skill.

**Architecture:** Keep the feature in three Canvas-safe units: layout segments and wraps graphemes, state derives all animation values from time, and the renderer draws the approved left-side card. Extend the existing registry and textarea control without adding a project-version change. Update the installed skill snapshot and validator so generated JSON is the source of truth for text, keywords, hold, exit, and card timing.

**Tech Stack:** TypeScript 6, React 19, Canvas 2D, Vitest, Testing Library, Python 3 `unittest`, Overlay Studio JSON v1.
